## 作品名称

**夜航 NightSail —— 大学生一人公司 AI 舰桥**

**关键词（3-5 个）**：AI Agent 工作流 · 一人公司（OPC）· 大学生创业 · 本地知识库 RAG · 纯静态零成本部署

## 作品概要（500 字以内）

「夜航 NightSail」是一个面向大学生的**一人公司（OPC）AI 创业舰桥**：把"从创意到上线"拆成五段航线——立意、侦察、造船、亮灯、顺风，由五位各司其职的 AI 船员协同完成——军师、侦察官、船匠、信号兵按工作流起草可直接使用的交付物：项目策划书、市场侦察报告、MVP 造船清单、亮灯发布包、增长信风计划，舵手负责流程编排与知识库调度；另生成单文件落地页与多渠道推广文案。作品内置本地知识库（自动分段 + 检索增强生成），课程讲义、访谈记录等资料可入库喂给船员，全程本地计算、数据不出本机。

夜航接任意 OpenAI 兼容大模型接口（本地 llama.cpp / 智谱 / DeepSeek 等），在无接口时以演示模式离线跑通全流程。整个作品**纯静态、零依赖、零服务器成本**：双击网页即可运行，托管到免费静态平台即完成上线。

夜航本身就是 OPC 模式的证言：它由一名大学生与 AI 船员结对开发，月运行成本约一杯奶茶，却完成了过去需要一个团队才能完成的产品设计、内容生产与运营交付——它演示的正是赛道题眼：**AI agent 如何帮助大学生个人或小团队完成从创意到落地的创业实践**。

## 教育痛点

1. **大学生创业"三座大山"**：没团队、没钱、没经验。传统组队创业的沟通对齐、股权分配、进度互等成本，恰恰吞噬了学生最宝贵的时间和试错速度。
2. **想得到，做不出**：学生有创意，但写不出策划书、做不了落地页、不会写推广文案；市面 AI 工具是"通用问答"，不提供面向创业全流程的**结构化工作流与可交付产物**。
3. **AI 用的贵、数据不放心**：商业 AI 订阅对学生是持续负担；校园项目的用户访谈、课程资料等数据上传云端存在隐私顾虑。
4. **创新创业教育缺"陪跑"**：高校双创课程多以理论授课为主，学生缺一个随时在岗、按商业标准输出交付物的"联合创始人"。

## 技术创新点

1. **五段航线 Agent 工作流**：不是单个聊天框，而是按创业阶段编排的**多角色 Agent 流水线**——每个航段绑定专职船员、独立提示词工程（要求表格化、可执行、有验收标准）、产出结构化交付物，前序产出自动注入后续航段上下文。
2. **本地优先的混合引擎**：一套界面兼容本地 llama.cpp/Ollama 与云端 OpenAI 兼容接口，断网可用演示模式兜底；密钥仅存本机 localStorage，实现"数据不出机"的隐私底线。
3. **可解释的本地 RAG**：知识库文本自动分段（200–600 字），中文 bigram 重叠检索、按相关度注入提示词，并提供"检索试验台"直观展示每次生成召回了哪些段落——检索过程对学生完全透明可解释。
4. **纯静态单页应用，零依赖自研**：无框架、无构建链路，含自研轻量 Markdown 渲染器与 canvas 尘埃粒子场；整站可放 U 盘、可挂校园网，双击即用。
5. **过程即证据**：航海志以 append-only 方式自动记录每个关键动作，可一键导出——把 OPC 的"迭代速度"变成可提交、可评审的证据链。
6. **可溯源的生成（反幻觉）**：产物中的市场结论带 [资料N] 徽章，点击即可回跳知识库来源段落与相关度；资料未覆盖的推断强制标注「待验证」——AI 生成内容"有据可查、无据声明"。
7. **互审与质检闭环**：每份产出由另一名船员按 rubric（可执行性/具体性/定位一致性）评分并出具评审意见，高优问题自动触发修订并标记采纳；薄弱项支持"定向修订"而非整篇重写。
8. **OPC 成本仪表盘**：每次生成实测调用次数、耗时、tokens 与按可配置费率折算的成本，按航段分账、累计到总览——把"低成本启动"从口号变成仪表盘上的实测数字。

## 落地场景

- **高校双创教育**：作为创新创业课程的"AI 陪跑教练"，学生带着点子进课堂，两课时内走完立意→侦察→造船，产出可直接路演的策划书与落地页。
- **校园服务轻创业**：学生个人用五段航线把校园服务点子（二手教材循环、课程评价聚合、社团活动策划）在两周内推进到真实上线。
- **任意静态环境部署**：整站为纯静态文件，可托管于 GitHub Pages、校园服务器或直接本地运行，零成本复制推广到任何学校。

## 应用成效

- **工作流跑通**：端到端演示可在 10 分钟内完成"命名一个点子 → 产出策划书/侦察报告/造船清单/发布包/增长计划 + 单文件落地页 + 4 渠道文案"的完整闭环（见演示视频）。
- **效率对比**：传统方式下上述材料一个人需 1–2 周；夜航将其压缩到**约 10 分钟的生成 + 人工审核修订**，且每份交付物可直接导出使用。
- **成本指标**：服务器与软件支出 **¥0/月**（纯静态 + 本地模型/免费 API 额度）；域名等固定成本 ≈ ¥8/月，满足"一杯奶茶预算创业"。
- **工程自证**：Playwright 自动化自检通过（起航 → 立意/侦察生成 → 落地页 → 文案 → 知识库入库与检索 → 航海志 .md 导出下载断言，控制台 0 报错），自检脚本随作品提交。
- ⚠ **真实试点数据（待补）**：建议邀请 10–30 名同学试用后补充：完成起航仪式人数、成功产出策划书份数、落地页部署份数、主观满意度（1–5 分）。评审最看重的就是这一节的真话。

## 原创性与 AI 使用说明

本作品由参赛学生本人设计并开发，开发过程使用生成式 AI 辅助编码与文案起草（这正是作品倡导的 OPC 工作方式），所有代码经本人理解、修改与测试；演示模式中的脚本文案为作品内置示例内容。作品不含第三方版权素材，字体（Figtree、JetBrains Mono、Material Symbols）均为 OFL/开源授权。
